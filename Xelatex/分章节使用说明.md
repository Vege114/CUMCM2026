# 论文分工修改说明

- 汇总入口：`数模通用模板.tex`。使用 XeLaTeX 编译此文件，工作目录为 `Xelatex`。
- 正文分文件位于 `sections`，文件名按论文顺序及章节命名；每人编辑负责的文件即可。
- 问题一至问题四分别为 `05-问题一.tex`、`06-问题二.tex`、`07-问题三.tex`、`08-问题四.tex`。
- 子文件通过 `\input` 汇总，不能单独编译；已添加编辑器主文件指向注释。
- 公共宏包、格式、论文标题在汇总入口修改；图片路径仍相对于 `Xelatex`，例如 `figures/...`。
- 新增公式、图表的 label 建议使用各章前缀（如 `q1:`、`q2:`），避免重复。
