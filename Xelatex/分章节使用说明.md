默认编译：

```bash
cd Xelatex
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build 数模通用模板.tex
```

构建得到`Xelatex/build/数模通用模板.pdf`；发布副本为仓库根目录`完整论文.pdf`。两者均为本地构建产物，不提交Git。
