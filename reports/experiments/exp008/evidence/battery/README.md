# 最终电池功率与强度证据

本目录只读取用户接受的冻结档案，不进行拟合或重新优化。来源、SHA-256、main 模板版本、预热衔接核验及图文件逐一列在 `manifest.json`。

- `battery_metrics_all.csv`：13 份正式或历史年度档案的强度及功率变化指标。
- `q2_vs_exp006_power_comparison.csv`：第二问与 exp006 的原值、绝对差和相对变化。
- `same_question_power_comparisons.csv`：各最终年度方案与同题历史基线的完整指标比较。第三问、第四问使用 exp002 对应问的正式档案。
- 各方案目录 `power_all_intervals.csv`：2025-02-01 至 12-31 的 334 日、48,096 个原始时点。不是 365 日；预热不拼入评分。
- 各方案目录 `power_YYYY-MM-DD.csv`：每条曲线完整 144 点。统一随机种子 20260912 抽到 04-15、06-07、12-06、12-25；指定日期 03-20、06-21、09-23、12-21 单独保存。
- `q1_deterministic_144_points.csv`：第一问附录 1 的一日确定性计划，其原始 c/d 已是 kW；未再次乘以 6。求解器约 1e-11 的负数舍入误差保留在原始列，以 1e-6 容差核验。
- `../../figures/battery/`：14 组图，各含 PNG 与 SVG。年度 SVG 的每条数据路径包含全部 48,096 点，关闭路径简化；日图无平滑、抽稀或补值。
- `independent_audit.json`：独立按导出 CSV 重算 13 组指标、连续十分钟时间轴、8 个完整日数据对应，并直接解析 SVG 验证数据路径点数。

母线净功率为 `P = 6 × (charge_kWh − discharge_kWh)`，正值充电。CSV 另存充/放电分量和期初、期末 SOC。功率波动按连续正式时间轴的 48,095 个相邻差分计算，含跨午夜，第一点差分为空；与预热末点的变化单独列示。功率变化及直接反转使用 1e-6 kW 容差，大跳变定义为超过 1000 kW/10min（仅描述）。非空方向反转、活动段计数沿用冻结实验的 1e-6 kWh 容差；前者移除空闲后计方向变化，直接反转只数相邻正负功率。二者不可互换。

第二问费用下降 6.1443%，非空方向反转下降 7.1821%，吞吐下降 1.1064%，总变差下降 7.3290%。但活动段从 3791 增至 3898，活动时段从 23028 增至 37211，直接相邻反转从 730 增至 1407。因此不能表述为全部充放行为均减少，也不能由这些代理指标推断寿命改善或统计显著性。最终方案没有额外爬坡硬约束；变化改善不可单独归因某机制。

exp001 保留原登记效率 0.9 和不同初始 SOC；exp005 β=0.1 从其原始分支不可变提交读取，包含额外爬坡约束且允许紧急电充电。两者在历史图中用斜纹展示，只作描述，不计算跨口径改善率。exp007 未纳入。
