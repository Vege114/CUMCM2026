# exp008 最终 Q2 预测敏感性与时间顺序回测

本次分析保留已接受的最终模型。所有原代码和冻结结果只读，未将得分较优的扰动参数替换为最终参数。

## 论文可用结论

- 原最终预测逐值精确复现：2025-02-01 至 12-31，共 334 日、48,096 个十分钟时段；净负荷 RMSE 357.162 kW，MAE 242.021 kW。
- 18 个单因素设置（含一个共同基准）覆盖融合权重、Ridge 窗口、Ridge 正则强度、昨日负载记忆。净负荷 RMSE 相对变化为 −0.241% 至 +0.698%。日总电量误差更敏感，RMSE 最大增加 3.063%，出现在将记忆系数从 0.5 降至 0.25 时。
- 在 4 月、7 月和 10 月起点真正重训，比较 7/14/21 日验证集。合并三个后续 28 日窗口后，净负荷 RMSE 分别为 379.666、378.048、379.796 kW。验证窗口变化没有使整体误差明显放大，但按月份观察仍存在方向不同的变化。
- 固定原 7 日验证方案的 4/7/10 月 28 日净负荷 RMSE 分别为 369.738、440.383、319.052 kW，月份差异明显大于本次局部参数变化。
- 核心树参数也完成真实重训：HGB 学习率从 0.08 调整为 0.064/0.096，ExtraTrees 叶节点最少样本从 10 调整为 8/12。三个 28 日窗口内，净负荷 RMSE 相对变化为 −0.972% 至 +0.661%，支持所检验邻域内的稳定性结论。

以上百分比均为相对原固定参数的误差变化，负值代表该误差降低；它们不是置信区间或显著性检验。2025 年数据此前已参与开发，因此本次是开发期敏感性和时间顺序回测，不能称为未触碰的独立测试。

各 CSV 的 `channel` 为 `load`、`pv`、`net`。功率单位为 kW、电量单位为 kWh。`*_change_pct` 以相同总体的基准为分母；CV 文件中的 `*_change_pct_vs_val7` 以同起点、同测试长度的 7 日验证方案为分母。

绘制每个后处理因子时，需要从唯一 `name=baseline` 记录补入该因子的默认横坐标：`weight=0.5`、`window=28`、`penalty_multiplier=1`、`gain=0.5`。核心树参数图同理按设置中的 `default` 补入基准。净负荷和两个通道可以分别绘制，不应将 kW 和 kWh 共用同一数值轴。

## 设计边界

原预测流程为 raw HGB/ExtraTrees 各占 0.5 → 两通道各自 Ridge28（包含跨通道特征）→ 昨日非递归负载记忆 0.5。Ridge 正则默认截距为 2、其余项为 20；强度扰动同时缩放二者。Ridge 窗口变化保留原规则“时间权重半衰期等于窗口的一半”，因此不能单独归因为窗口长度。

训练从 2025-01-08 起扩展，到验证窗口前一日结束；验证窗口位于每个起点之前。HGB 使用显式时序验证进行早停，ExtraTrees 只用验证集记录误差。4/7/10 月各自起点以后固定原始树模型 28 日，每日 00:00 发布未来 144 槽，特征及后处理只使用已结束的前日数据。7/14/28 日是同一真正重训预测序列的嵌套评分窗口，不代表三组独立样本。

各方案在起点前共享原先已经发布的冻结 raw/Ridge 历史作为暖启动，起点之后使用新方案自己的逐日预测；不事后生成训练内预测来冒充已发布历史。这是“起点切换方案”的检验，不是各方案从 1 月开始重新运行全年的结果。核心树参数扰动只重训被改变的一类树；另一类使用已验证与真实重训基准一致的原冻结预测。

所有 334 日基准输出与原冻结结果逐值相等。三个 7 日验证方案重训后，最终预测与对应原月归档最大差值为 1.82×10⁻¹² kW。126 次未来扰动检查、所有后处理标签边界检查、重训特征/标签的未来扰动检查均通过。关键误差指标另用 Python `math.fsum` 独立复核，逐日与聚合值已对账；原始来源哈希在结束后保持不变。

`hyperparameter_cv_input_crosscheck.json` 另行逐一对比 12 次核心树参数重训与对应 7 日验证基准的四个真实训练/验证数组哈希及三个时间边界，48 个数组哈希和 36 个边界全部相等。该交叉核验明确验证了补充训练审计中“沿用相同因果输入”的记录，没有修改此前源码或重训结果。

仅使用 seed 42，不作跨种子或跨年度稳定性推断。预测误差变化不能直接代替调度成本变化。

复现入口：先运行 `experiments.exp008.robustness.forecast_analysis`，再运行 `experiments.exp008.robustness.forecast_hyperparameters`，使用仓库 `.venv/bin/python -m`。脚本拒绝覆盖已存在的结果；原输入签名见 protocol/summary，主分析与树参数补充各有独立输出清单和源码快照。
