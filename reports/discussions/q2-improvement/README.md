# 第二问人工讨论报告

阅读 `report.html`：完整 HTML 内嵌所需数据与共享运行时，可独立打开。它采用新的会议结构，不修改 exp003 算法，也不启动新的模型实验。

本报告将第二问拆成 7 个可分工模块，列出 12 个技术决定、33 个选项。每个选项解释题意上的问题、实际做法、收益、代价、组合条件及按购电费用验收的方式。会议记录默认未选择，可填写负责人、理由并导出 JSON 草稿。

绩效只包括题目直接要求的总购电费，以及计划购电费、紧急购电费两项构成。负载/PV、电价和电量图用于理解题目数据，表1—表3及储电量图用于检查题目要求的运行输出。

## 随包文件

- `evidence.json`：365 天原始负载/PV、固定电价；4 种已运行策略的 334 天费用；四指定日及当前总费用最高日的调度明细。
- `build_evidence.py`、`evidence-audit.json`：记录证据从附件及已保存结果重建、核验的方法和结果。
- `modules.json`、`modules.md`：7 个模块、输入输出、所有选项及基础解释。
- `discussion-options-log.md`：在展示技术选项之前保存的完整讨论日志；不覆盖既有 D001—D006 决策。
- `build_report.py`：只从随包 JSON 构建新 HTML，不依赖 exp003 训练代码或 GPU。
- `app/`：新的共享运行时报告工程，保留稳定 artifact ID。
- `report-build.json`：证据和最终 HTML 的构建哈希。
- `build_inline.py`、`inline-overview.html`：供 Visualize 在聊天中呈现的证据概览。

模板在 `reports/templates/q2-discussion/`，其中 `template.html` 可独立使用，不包含实测图表数值。

## 重建报告

在仓库根目录：

```sh
python reports/discussions/q2-improvement/build_report.py --complete --template
```

构建需要本地 Data Analytics 插件的官方运行时。另一个环境可通过 `--node` 与 `--plugin-root` 指定路径；已经交付的 HTML 不需要构建依赖。`build_report.py` 在 main 分支也只读取本目录随包 JSON。

`build_evidence.py` 用于从原始试验仓库重新采集证据，需要源附件和 exp003 结果存在；main 若未包含这些实验文件，不运行此采集步骤，仍可独立阅读或从已核验的 JSON 重建 HTML。

## 费用口径

- 原始数据：2025 年 1 月 1 日至 12 月 31 日，共 365 天。
- 正式费用：2 月 1 日至 12 月 31 日，共 334 天；一月训练、调参和共同预热不计入正式费用。
- 每天 00:00 锁定全天计划；计划电量全部付费，紧急购电单价为正常电价的 5 倍。
- 功率单位 kW，10 分钟电量为功率除以 6；储能剩余电量以 kWh 表示。
- 四方案同一储能和结算口径；v2 训练目标曾与其他问共同早停，所以费用差不能只归因于某个单独预测改进。
- exp003 最终 α=(0,0)，与周期预测的微小费用差属于数值差异，不代表神经网络带来费用收益。

本页所有新选项均未开始实验。浏览器会议草稿与证据快照分开，不修改任何模型、源数据或配置。
