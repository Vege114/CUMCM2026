# Q2 历史基线独立证据

仅归档现有预测与费用，不训练、不回放。复现：

`.venv/bin/python -m experiments.problem2.exp003.baseline_evidence`

预测统一使用每日0时的144区间，2—12月共48,096区间。负载、光伏、净负载均保留全天与实际光伏>0两种人群；净负载不裁剪。MAE/RMSE/bias单位kW，WAPE单位%；bias=预测−实际。月度值通过误差和汇总，全年直接评分。

旧v1/v2网络用四目标共同验证损失选择保存轮次，附件3/4可能间接影响Q2；午夜筛选不会消除这一耦合，不能宣称历史网络严格输入隔离。旧v2周期等费用也仅保留原执行证据，不追认原运行输入隔离。attachment2_*预测由本脚本仅用附件2历史重建，与原费用分列。

exp001_original_q2_costs.csv为旧协议原登记值，不参与v2费用排名；exp002_q2_costs.csv中的legacy_rebased才是v2物理/预热/执行口径下的历史重算。若exp003改变这些口径，所有历史费用都需在新协议重算。

manifest.json保留两代原协议、原月度选择、所有读取源的SHA256和口径；baseline_boundaries.json为每个预测器及费用方案保存边界标识。大数组只保留负载/PV；净负载由两列相减。CSV中的空指标表示零分母或空人群。
