# 累计净电量损失的固定网络对照

网络仍为共享卷积、4850参数；输入、月度训练与前7日验证、种子42、CPU及全部训练边界均沿用 Joint CNN。仅增加一个固定权重1的累计净误差 Huber 组：先将净负荷误差除以训练截止前净负荷标准差，再对日内前缀求和并除以该前缀长度平方根，按已知电价加权。该项是储能累计误差代理，不是实际购电费或最优性证明。

11个月训练均完成，手算损失/正负对称性、保存重载及未来实际变异检查通过。之后使用完全相同的 Ridge28 和固定0.5日负载能量记忆进行公平比较。

| 指标 | 原Joint+Ridge28+Memory | 累计损失CNN+同后处理 |
|---|---:|---:|
| 净需求RMSE / kW | 375.585 | 380.384 |
| 高价净需求RMSE / kW | 358.230 | 363.327 |
| 日净能量RMSE / kWh | 3723.897 | 3852.287 |
| 累计前缀RMSE / kWh | 2351.532 | 2410.390 |

没有通过预先记录的三个误差指标同时改善门槛，因此不启动购电规划桥接，不继续调损失权重。2025年已被用于开发，不能称为未见测试年。

归档元数据勘误：`memory_audit.json` 最初沿用可复用 EnergyMemoryStore 的 `underlying_forecast=joint_CNN_then_fixed_Ridge28` 固定文字，但实际数值传入的是本轮累计损失CNN的Ridge28输出。已保留原始源快照与数值归档，并在 `audit_metadata_correction.json` 明确该字段应为 `cumulative_loss_CNN_then_fixed_Ridge28`；调用器源码已修正未来归档标签。该文字勘误不改变预测、评分或因果边界。
