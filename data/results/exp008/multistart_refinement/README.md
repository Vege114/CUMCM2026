# 固定双初值闭环优化诊断

采用 memory 物理三场景参考的前5个评估日，每日分别固定其SOC、小时模式和28条当时可得历史路径。原初值为已归档的三场景MIP购电量；第二初值为同预测风险树的0.8分位LP购电量。两者都用原闭环目标和120次迭代；仅按历史目标选择更优解，再使用实际数据结算。

原闭环优化购电量逐值重现，最大误差0。第二初值在4天被历史目标选中，五日历史目标总计低169.87元；实际账单合计却由262,337.00变为263,765.16元（增加1,428.16元）。所选方案各日末SOC合计比参考高3,394.55 kWh，没有用额外库存抵扣实际费用。

这些是五个同起点条件干预，各天末SOC不同，不能拼成一条连续五日策略，更不能外推年度收益或证明长期变差。十条单日轨迹的物理与分项结算均通过。未发现值得立刻扩大回放的明显改善，当前不继续增加初值或做年度扩展。该诊断不进入目标结果索引。
