# Q4 价格与净需求误差：存在稳定关联，但不能把关联额当成节约

本诊断只读取冻结预测和七个完整年度调度归档，没有求解新全年策略。残差统一定义为“实际减发布时预测”。Q4-3 每个六小时执行段使用该段之前最近一次合法发布；原计划费用的预测价仍取午夜版本。

## 执行后的统计诊断

| 预测 / 场景 | 价格与正净误差相关 | 去同槽均值后的相关 | 正净误差加权价格低估（元/kWh） |
|---|---:|---:|---:|
| base / Q4-2 | 0.362 | 0.365 | 0.06042 |
| ridge28 / Q4-2 | 0.488 | 0.504 | 0.05176 |
| base / Q4-3 最新发布 | 0.264 | 0.270 | 0.03185 |
| ridge28 / Q4-3 最新发布 | 0.308 | 0.316 | 0.02890 |

价格的普通平均残差接近零：Q4-2 为 −0.000021 元/kWh，Q4-3 为 +0.000048 元/kWh；需求缺口加权后却明显低估。ridge28 Q4-2 的正净误差相关在春/夏/秋/冬分别为 0.502 / 0.560 / 0.471 / 0.350；Q4-3 为 0.260 / 0.376 / 0.298 / 0.252，四季均为正。去掉同一个十分钟位置的平均差异后，关联仍保留，因此不仅是一天内时段构成造成。

按完整日重采样的描述性 95% 区间：ridge28 Q4-2 正净误差加权价格低估为 [0.04548, 0.05815]，Q4-3 为 [0.02424, 0.03323] 元/kWh。重采样保留日内相关，但不完全保留跨日序列相关；这些区间和全年统计只用于诊断，没有进入策略训练或调参。冬季只有评价期内的二月、十二月，不包含一月预热。

真实已执行紧急电量也与价格误差同向。Q4-2 旧迁移 / joint / calibrated 三组紧急电量加权低估分别为 0.07772 / 0.05351 / 0.07575 元/kWh；真实紧急费比用发布价给同一紧急电量重计多 61,270.74 / 62,375.65 / 49,627.64 元。四季加权低估均为正。Q4-3 最新组合候选的对应值为 0.05225 元/kWh、12,446.25 元。紧急槽稀少，所以全槽 Pearson 相关较低；加权货币差更直接体现暴露。

这些金额不是可通过算法取得的收益：实际回放费用一直用真实交易价结算，完全没有低记账。诊断揭示的是原优化目标对高缺口情景的价格风险刻画不足。

## 当时确实可以构建的风险样本

午夜调用冻结 `Forecasts.net_error_paths` 的同日配对；日内用相同规则的 `issued_error_paths`，避免再次混用午夜与更新后的残差。每行的净需求残差与价格残差来自同一个已完成的历史发布日，行索引不能独立排序或随机打散。

给当前预测加配对价格误差并截正到 0.01 元/kWh：`P[j,t] = max(.01, p_hat[t] + price_error[j,t])`。历史样本中“5P × 正净误差”代理，保持真实配对与将价格、误差独立配对相比，全年累计代理差额约为 base Q4-2 15.28 万元、ridge28 Q4-2 29.06 万元、base Q4-3 9.44 万元、ridge28 Q4-3 12.34 万元。相比之下，仅用历史平均价格残差的代理增量约为 0.33–0.78 万元。Q4-2 每个午夜配对协方差增量均为正；Q4-3 约 98.7% / 99.1% 发布点为正。

这里没有电池或最优紧急补救变量，只是 **正净预测误差** 的价格权重诊断，不能把代理增量当作真实紧急费、可达下界或预计节约。详细每次发布样本来源、标签界与代理值存于 `paired_history_*.json`；完整统计、季节/月度结果与调度文件哈希见 `results.json`。

## 有依据的实现方式

净需求路径 `net[j,t]` 和价格矩阵 `P[j,t]` 共享历史行。共同购电量 q 在目标里只支付一次 `mean(P,axis=0)·q`；每条路径的紧急费使用该行的 `5*P[j,t]*e[j,t]`，再对路径取平均。Q4-3 更新时共同上调量按 1.5 倍当前场景价计，原计划费用保留为常数；若使用后续更新机会代理，仍要逐路径乘相应价格。

初始化模型与后续 greedy 梯度修正必须同时改成配对价格，否则后一步会覆盖前一步的风险偏好。终端库存代理、物理约束、模式代价和路径数先保持不动；三路径初始化的净需求和价格必须用相同三个索引。只把真实当前价格留在执行后结算，不能拿目标日未来价格作为情景。

据此完成的固定 30 日候选另外记录在 `../q4_joint_price/README.md`。关联存在不保证某个近似规划器、模式选择和有限样本配置必然取得实测费用优势。
