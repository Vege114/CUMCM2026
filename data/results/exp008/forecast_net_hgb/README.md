# 固定月度净需求 HGB 残差试验

单一预列模型，保留 CNN 基线及其预测作为特征；每月初用此前全部已完成日重新训练。共11个模型，35维特征，平方误差损失、15个最大叶节点、100轮、最小叶样本50、L2=2、学习率0.08。训练历史样本的特征也严格截止各自发布时刻，一月只采用因果周期冷启动。未引入官方光伏预报、未来实际电价或年度全局实际特征。

本轮净需求 RMSE 为441.40 kW，弱于既有因果 ridge_28 的387.68 kW。比较固定电价上四分位时段（价格≥0.984475元/kWh），HGB 的 RMSE/MAE 为412.26/290.51 kW，ridge_28为371.75/267.02 kW；电价加权 RMSE 为441.06 对389.50 kW。HGB高价时段的低估电量较少，但同时出现+39.94 kW偏置，不能解释为更准确。该单候选未体现相对ridge的优势，按预定边界停止进一步HGB调参。

预测值是净需求adapter：净修正首先加到负载列，极端负值通过两列共同平移保持非负并严格保留预测净需求。两列不能作为独立改善后的负载和光伏预测评分。原始CNN、净修正、完整净预测、adapter和误差均保存在predictions.npz。模型权重在models/，月份训练与每天发布边界分别在training_audit.json和prediction_audit.json。

4项独立核验通过：四个时间切点的未来扰动不影响当天特征；月初之后真值及特征扰动不改变该月模型；adapter和净修正可精确重构；11个月训练和334日发布全部满足严格信息截止。详见verification.json。

这是对已经查看年度的开发探索，不是独立测试。tariff_error_comparison.csv同时保留原CNN和ridge对照。无储能费用代理只作误差经济方向诊断，不能冒充实际调度费用。

复现：`LOKY_MAX_CPU_COUNT=1 .venv/bin/python -m experiments.exp008.forecast_net_hgb`。设置单核数避免当前主机物理CPU枚举权限不足告警，计算仍由threadpool_limits限制为单线程。
