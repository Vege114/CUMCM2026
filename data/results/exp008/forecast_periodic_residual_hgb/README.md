# 唯一统一周期基底残差标签对照：未接 LP

本候选只改变前一绝对值 HGB 的标签与输出重构：负载标签减去上周同槽实际负载，PV 标签减去昨日同槽实际 PV；预测时加回当前发行前已经观测到的同一基底。从训练起始的 1 月 8 日至 12 月，定义始终一致，没有一月 periodic → 二月 CNN 的参考切换，也不使用任何 CNN 标签。

31 个输入特征的完整 tensor hash，以及 11 个月每月训练/验证特征 hash，与绝对值 HGB 完全一致。模型复杂度、月度过去数据训练/最后 7 日验证、固定早停、seed42、90 日年龄权重、非负与过去 28 日日照并集扩 20 分钟遮罩，均保持相同。两通道输出随后固定经过相同 Ridge28 和非递归 gain=0.5 memory，没有根据全年分数选择后处理。

协议在训练前记录。直接标签对照为当时已通过门槛的绝对值 HGB 完整管线；Joint + Ridge28 + Memory 继续作为第二对照。主门槛要求净、高价、日累计三类五项误差均改善，才运行固定 LP 桥接。

五项均未超过当前绝对值 HGB，故 `dispatch_gate.json` 为 false，**未运行 LP、未调参、未改当前预测/控制器或最终模型选择**。统一周期基底的原始净 RMSE 424.107 优于绝对 HGB 原始 433.740，但原始高价误差更差（393.491 vs379.840）；加上预先固定后处理后，主比较全面落后。因此不能用原始净误差单项优势替代整个门槛。

完整管线仍略优于旧 Joint + Memory（净 375.585，高价 358.230，日能量 3723.897，累计 2351.532），但没有改用这个较弱对照来启动更多规划实验。树模型借助周期基底外推已观测负载幅度的动机合理，这次唯一固定实现未表现出比当前完整管线更好的误差。

22 份完整模型、训练/验证/正式月边界、334 日原始/Ridge/Memory 预测、逐日/月/年分通道误差与来源 hash 全部保留。模型保存重载、7 组未来数据/未来后处理预测污染、2 月与 9 月完整重训污染均通过；独立核验还手工检查了 6 个历史/正式发行点的周期基底与严格标签边界。见 `causality_verification.json`、`independent_verification.json`、`training_audit.json`。
