# 固定 0.5 / 0.5 预测融合：全年 LP 桥接诊断

本目录只保存一个预先固定候选，不是最终报告或最终模型选择。融合两条完整管线的最终输出：绝对负载/PV HGB → Ridge28 → 0.5 日能量记忆，以及 Joint CNN → Ridge28 → 0.5 日能量记忆。每槽两通道各取算术平均，融合后不再校准、不拟合权重，也不搜索其他比例。原始两条管线未改动。

2025 年 2 月 1 日至 12 月 31 日共 334 日是开发探索评估，不能称独立测试。根任务先前固定的点预测诊断位于 `../forecast_ensemble_diagnostic/`，本目录 `protocol.json` 在因果检验和桥接运行前落盘。

均值总费用增加 0.1649%。若把更低末 SOC 按最高固定时价的紧急购电替代价值作保守补偿，增加费用为 22,196.99 元；这个附加值只作终端状态敏感性诊断，不改题目账单。7 个月费用增加，4 个月减少，分项见 `monthly_comparison.csv`。

此前固定点预测诊断的净负荷 RMSE、高价时段 RMSE、价格加权 RMSE、日净能量误差及日内累计误差均略降，仍未带来本执行器下的费用收益。成本为主目标，本轮不建议据此进入后续物理规划，不再调权。相对 exp006 的 Q2 目标也未达成：只降费 6.1930%，反转仍为 6,873。

## 信息边界和独立核验

- 两条原始输入的文件 hash、值 hash 均核对根诊断签名；334 个午夜发布日期完全一致；每个输出槽与 `0.5 * HGB + 0.5 * Joint` 严格相等。
- 用各原始已发布预测重新计算双方 Ridge28 和记忆后处理，融合结果严格复现存档。五个发行截点改变本日及未来实际值、未来原始预测，再重算完整后处理；截至截点的融合预测与当日树支持保持逐值不变。
- 三个新的发行适配器测试改变发行之后的全部实际通道及未发布附件 3，Q2/Q3/Q4-3 对应输出不变。上游 CNN/HGB 拟合因果性由复制保存的原始训练边界及扰动审计支撑，本实验未重新训练上游模型。
- 风险支持由融合后的历史发布预测和此前完整日实际误差重新训练；前两日保持原算法标注的一月周期冷启动。历史条件分布是逐槽边际分位数，并非完整联合随机路径。没有平均两条旧风险支持，也没有复用旧风险缓存。
- 另一个只读验证入口重算 334 日树支持、核对 334 日午夜适配值和 140 条历史完整误差路径。`adapter_and_risk_verification.json` 保存结果。
- 两份全年轨迹均用独立核验器对原始数据重算账单、能量平衡、效率、功率、SOC 和跨日连续性。充放强度仅是运行代理指标，未宣称真实寿命或容量衰减改善。

## 可复用接口与文件

`experiments.exp008.forecast_half_ensemble.EnsembleStore()` 提供 `values`、`origins` 和 `get(origin)`；`EnsembleForecasts()` 提供 `get(day, slot, scenario)` 和同模型历史误差。`audited_forecasts()` 增加明确模型 ID、预测与源文件 hash，可接现有 `run_case(..., forecast_override=...)`。本轮只桥接 Q2，没有运行融合版 Q3/Q4 年度执行。

全年轨迹：`lp_bridge/half_ensemble_tree28_q08_buffer500_334days/dispatch_2.npz`。同目录有逐日费、支持、发行审计、独立核验。目录根提供 `comparison.csv`、`daily_comparison.csv`、`monthly_comparison.csv`、`summary.json` 和源快照。

复现入口：`.venv/bin/python -m experiments.exp008.forecast_half_ensemble`；若输出目录已存在会拒绝覆盖。只读核验入口：`.venv/bin/python -m experiments.exp008.test_half_ensemble`。
