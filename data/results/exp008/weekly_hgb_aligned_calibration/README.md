# 每周HGB与当前模型校准参考对齐：候选失败

复用已冻结的48组每周HGB模型，不重新训练。每个发布日用当前模型，对其验证周及训练后已经完成的日期重新预测，构造7至13天校准样本；保留原Ridge28的特征、正则项、14日权重公式及非递归0.5负荷记忆。

这些历史重新计算值是**当前模型的历史回算**，并非历史日期当时发布的预报。其标签未参与原始HGB梯度训练，但验证周已用于早停选择，因此校准样本并不独立于模型选择。全部标签在当前发布前已知；实际新发布档案仍用于后续风险历史，不能把历史回算冒充当年已发布预报。
