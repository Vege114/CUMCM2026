# 四块采购策略的决策导向训练：60日pilot

固定一个配置，没有继续扫参数。CNN及q=0.8 LP提供当天原计划g0；8维发布时刻特征通过4×8矩阵W给出四个六小时块的采购修正，再逐槽应用非负截断。每个策略按自身真实日初SOC重新规划g0，SOC连续传递。基线为W=0，与学习策略使用完全相同的贪心储能执行器。

每月仅使用此前28个完整历史日。历史lp_q0.80_statebuffer500档案提供训练g0及当时日初SOC；训练损失重新通过贪心执行的真实购电账单计算，没有把statebuffer的旧账单当监督目标。实际净负荷仅作为已经揭晓的历史监督标签。训练特征也只读取该历史日发布前信息。二月样本不足，W严格冻结为0；三月与四月分别使用各自月初之前的28日训练。

目标为平均每日题目真账单加L2正则，闭环目标的期末残值、吞吐费、功率变差项都设为0。L2系数为0.5元/(kWh系数)²；W每项限制在±150kWh。优化上限300轮，实际三月39轮、四月15轮数值收敛；不具有全局最优保证。六个系数方向的有限差分检查与发布时刻未来扰动检查通过。

历史训练账单下降：三月训练窗口的日均账单42005.8044→41823.1779元；四月34969.8355→34759.3782元。然而2025-02-01至04-01的60日因果重放中，零修正基线费用2317122.2280元，学习策略2318348.2150元，增加1225.9870元（约0.0529%）。排除二月冻结期后增加约0.1075%。非空方向反转1506→1524，活动槽7482→7460，吞吐2292144.60→2287989.28kWh。

两策略完整供需平衡、SOC递推、跨日连续性、互斥、功率、容量和费用复算通过。采购修正是有符号量，单独核验g0+修正=最终采购；没有把负的采购修正误当作负物理电量。二月两个策略逐槽一致。

本pilot没有显示费用改善，按预设“训练目标降而真实重放升则停止”规则，不扩展到全年，不继续调分块数、特征或正则。60日结果不能宣称满足334日年度主目标，也不是独立测试集结论。

完整证据：protocol.json、training_m*.json、gradient_and_causality.json、paired_daily.csv、summary.json，以及两策略各自的dispatch_2.npz、audit.json、daily.csv和verification.json。复现程序为experiments/exp008/policy_calibration.py，输出目录存在已完成summary时会拒绝覆盖。
