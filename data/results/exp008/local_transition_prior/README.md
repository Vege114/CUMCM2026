# 局部时刻转移先验诊断（未选为最终成果）

该固定候选只将三状态误差 Markov 模型在非午夜时点的收缩先验，从全时段汇总改为相邻前后各六个十分钟时点汇总。所有统计仍来自已完成的28条历史误差，条件发射支持、状态边界、当前预测和午夜初始化保持不变。局部计数同时进入先验与当前行，因此属于平滑估计，不是独立先验数据。

334日全部模型先锁定，再读取当前日实况评分。单步对数损失从0.8583405025降至0.8530448856，Brier分数从0.5173194254降至0.5157026929。47,762个标量先验行重算、2,004个未来评分扰动核验通过。

随后固定五个日期31/90/151/243/364、原HGB方案各自的购电量和日初实际状态，保留grid200/cap8的反馈DP。相对原DP，五日条件费用合计减少764.4862元，历史目标减少191.1265元，换向数不变、启停段增加1、吞吐增加240.0767kWh。1,350个独立标量Bellman检查最大差1.46e-11，15个未来扰动检查通过，原DP实际流逐值复现。

这些不是连续全年费用，也不是未触碰测试集结果。用户随后接受当时已有的完整全年版本，要求停止优化并写报告，因此本候选不扩展、不进入最终选择。最终Q2仍为已完成的HGB/ExtraTrees融合预测与固定hold1/cap8模式方案。
