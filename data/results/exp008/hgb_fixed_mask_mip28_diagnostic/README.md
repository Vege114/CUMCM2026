各例初始 SOC、初始方向、小时模式 mask 和全部 28 条因果历史路径都取自原 HGB physical3 年度档案。没有改变预测或模式，也没有把五天串成连续策略。五例反转数均与原档案相同。实付变化合计 −905.39 元不能视为连续策略节省，前三例末 SOC 消耗较多。

MIP 去除共同模式及切换决策变量，固定切换成本作为常数；保留逐场景禁止紧急购电充电的分支变量。电池功率、效率、SOC、共同购电上界、账单和两阶段各自 terminal 均沿用原实现：MIP 非末日末 SOC 系数为 `min(price)/η`；greedy 非末日为 `0.45*(SOC_end−LOW)`。每例上限 30 秒、gap 0.002；现有 scipy 接口无 warm start 参数，未使用，也未延长时间。场景 MIP 仍允许场景内预知其自身未来，不能称为非前视控制证书；最终筛选使用真实因果 greedy 在同 28 条已完成历史误差路径上的目标。

原 3 场景初始购电重新运行同 mask 的 greedy120，五例修正后购电及当天执行所有数组都严格复现原档案。新 MIP 初值未经 greedy 修正时，五例历史闭环目标全部更差；经过修正才获得表内微小优势，不能宣称 MIP 松弛目标本身等同真实控制器目标。

新旧 q 的选择根据独立重算的历史目标，在 `selection_locked_before_actual.json` 落盘后才读取本日实况。独立核查了 28 路径 MIP 的平衡、SOC、功率、无同充放、无紧急充电、无放电入弃电，以及 greedy 的全部状态和分项目标。五次未来实际与未来预测变异没有改变历史路径、问题输入或已存候选的历史选择；该核验没有重复 MIP 求解。

`summary.json` 中 `worth_full_trial_on_historical_objective=true` 仅代表五例存在正的历史目标改善，不是根任务批准扩年；本目录最终处置为不扩年。全部原始输入和共享源码 hash 保持一致。

主入口：`experiments.exp008.hgb_fixed_mask_mip28_diagnostic`。独立核验：`experiments.exp008.test_hgb_fixed_mask_mip28`。每例目录保存 solver primal/dual/gap、全部历史场景状态、独立 greedy 数组、选择锁定记录及孤立日核费；未加入正式 dispatch 索引。
