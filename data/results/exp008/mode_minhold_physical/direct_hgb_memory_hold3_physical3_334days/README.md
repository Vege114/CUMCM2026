# Absolute HGB与10分钟可变模式：334日预登记回放

本目录对应一个固定配置：Absolute HGB→固定Ridge28→负载日均残差0.5记忆，接共同购电的物理3历史场景MIP。充放模式可在任意10分钟边界改变，但每一模式至少保持3槽。前3天只检查可行解、场景物理、独立来源/执行核验及gap≤0.05，费用和动作数量不参与通过判断；通过后在同一进程内延续SOC、计划模式和模式年龄，已完成2025-02-01至12-31的334天。该年是已分析过的开发年，不是独立测试集。

## 固定控制协议

- 初始化从过去28个完整日同一HGB预测链的整日净需求误差中等距取3条场景；1月历史使用原有明确标注的因果周期冷启动。
- 共同计划购电；各场景SOC/功率约束、充放互斥与紧急购电不得充电的硬约束继承原physical模型。切换辅助项50元、吞吐辅助项0.002、求解5秒、目标gap 0.002不变。
- 每个10分钟时点使用一个计划模式变量，翻转是相邻模式的精确XOR，任意连续3槽翻转数不超过1。午夜翻转同样计入辅助项。
- 上一计划模式和已经持续的槽数显式跨日继承；尚未完成3槽的保持义务锁定下一日开头相应槽。warmup已知末槽充电，保守记年龄1，所以最初2槽固定充电。
- 购电修正继续使用全部28条历史路径，原贪心物理目标、maxiter120、wear 0.002、variation 0、deadband 0。终端代理与固定小时物理策略相同：MIP为最低电价/效率，贪心为0.45；仅12月31日两项均为0。
- 真实执行严格遵守已发行mask，连续SOC，当前实际只在该槽执行时进入；账单只计计划费与5倍紧急费，辅助罚项和库存代理不计入题目账单。

计划模式的最短保持不等于电池实际非空动作的最短保持；允许充电时没有盈余可以闲置。实际非空反转、活跃槽、吞吐和爬坡分别统计。场景内递推仍具有路径各自的乐观未来动作自由度，因此不宣称完整非前视多阶段最优证书。

## 归档和独立检查

入口为 `experiments/exp008/run_hgb_mode_minhold.py`，计划实现复用已核验的 `mode_minhold_physical.py`，独立审计为 `hgb_mode_minhold_audit.py`。未修改原固定小时physical、原HGB预测或其他已完成档案，未复用不同预测的前缀。

`evaluation_protocol.json` 在执行前保存，`complete_provenance.json` 记录源码、全部预测文件、22个HGB模型、原始数据和发行数组的哈希。`source_archive/` 包括导入依赖；归档一个源码不代表执行了其中所有模型。`forecast_archive/` 保存原始HGB、Ridge28、记忆、训练边界和预测因果记录；当前发行数组独立保存在 `issued_forecasts.npz`。

每10天保存执行检查点，全部每日3场景流量、SOC、完整28路径和继承模式状态单独归档。独立核验从原始CSV和归档发行预测重建历史风险，核查物理与账单、跨日状态、HGB重载、预测/风险路径未来变异及每天3次执行前缀未来变异。`first3_dispatch.npz` 固定记录本次自己的前缀，年度完成后必须逐数组相同。

年度指标以完成后生成的 `summary.json`、`paired_comparison.csv`、`monthly_comparison.csv`、`paired_findings.json` 为准。完整年度对照为相同HGB链的固定小时物理策略以及exp006，部分年度检查点不得代称年度达标。

全334日独立审计已经通过：1,002条规划场景的物理检查、所有28条风险路径及3场景选择与同HGB小时模式逐数组一致、1,002次执行未来变异、7个发行日的模型重载/预测/风险路径未来变异、全部源码/模型/预测哈希及本次首3日逐数组检查通过。最大数值误差4.41e-8。计划模式换向1827次，其中1481次在非整点；实际非空反转1801次，两者定义不同。期末模式已经保持37槽，无未完成的最短保持义务。

334日全部有可行MIP解，平均求解3.282秒、合计1096.047秒、最大5.030秒；平均gap 0.003059、最大0.038534。79日达到5秒时限，所以不能宣称所有日均达到0.002目标gap。购电修正固定120步，61日按相对目标变化收敛、273日达到迭代上限；仍全部通过真实物理/账单核验，但没有优化收敛或全局最优证书。
