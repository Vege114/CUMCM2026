# 条件边际与历史秩相关的风险诊断

固定使用 Joint+Ridge28+0.5负载能量记忆。参考方法为此前28个完整日期的同管线净负荷误差路径；对照把这些历史日的逐槽秩映射到原树模型的当前条件边际分位点，保留历史日的秩相关结构。没有重新选择树深、样本量或分位点。

全年334日、每个预测/风险路径构造后才读取当天实际值评分。经验CRPS使用包含对角项的V统计量，同一天两方法样本数量相同。

| 指标（越小越好） | 原始历史路径 | 条件边际秩映射 |
|---|---:|---:|
| 电价加权逐槽CRPS | 32.6077 | 33.2525 |
| 日内累计前缀CRPS / kWh | 1079.7947 | 1104.4007 |
| 全天净电量CRPS / kWh | 2031.6620 | 2078.5661 |

条件映射的80%分位覆盖率0.7924比原始0.7835更接近0.8，但三项完整分布评分均变差，因此没有通过预设继续条件，不启动物理规划。该结果只针对这一种固定经验copula实现，不能推断所有条件风险模型都无效，也不代表实际购电账单。所有历史标签均早于各自当前发布时间。
