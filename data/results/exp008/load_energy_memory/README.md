## 接口与复现

`EnergyMemoryStore()` 提供 `origins`、`values`、`base_values`、`delta`、`audit` 和 `get(origin)`；`EnergyMemoryForecasts()` 可直接传给物理规划的 `forecast_override`，继承历史风险方法会调用同一memory管线。

预测审计：`OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python -m experiments.exp008.load_energy_memory_audit`。

快速桥接：`OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python -m experiments.exp008.load_energy_memory_bridge --forecast both`。

源/数据/预测散列由各自protocol保存；完成案例只接受相同来源，变化时拒绝复用。2025已被查看和用于开发，以上均不是独立样本外验证。
