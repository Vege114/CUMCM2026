# 24维小时购电偏移：5个同起点条件比较

基线为`mode_planning_physical/load_memory_half_physical3_30days`，固定前5个正式日31–35。每一天使用基线已保存的初始SOC、模式mask、28条历史净需求路径及同日已发布memory预测。原144维购电取`dispatch.npz`的`original`，不是`planning_day`内的MIP初始化购电。

候选`q[t]=max(0,forecast_net[t]+delta[hour(t)])`，共24个变量，单位为每十分钟kWh。初值为原购电减预测净需求的每小时均值。单日所有变量边界为`±(5000/6 + max(abs(historical_net_paths−forecast_net)))`。优化原`closed_loop.objective`，mask不变、wear=.002、variation=0、terminal=.45、deadband=0；L-BFGS-B固定最多120轮。解析梯度按小时累加原q梯度乘`forecast_net+delta>0`。没有调参或事后选择测试日。

程序完成全部5天优化后才实例化实际数据进行执行与结算。当日实际值未进入优化函数。5天各自沿用对应基线起点，不把候选前一天末SOC接到下一天，因此以下是条件比较，不能当作连续替代或年度策略。

原费用合计262337.00元，候选264142.62元，增加1805.62元（0.688%），仅1日省钱。候选每天末SOC都更高，因此`max(0,原末SOC−候选末SOC)×η×5×最高固定电价`的保守补偿均为0；高出库存的价值未抵扣题目实际账单。这个条件比较没有清晰收益，不扩展30日或全年。

候选历史目标虽然相对其24维投影初值全部改善，但五日都高于原144维refined购电，分别增加466.88、808.62、932.46、706.56、911.33元的规划代理目标。该目标已包含同样的末端SOC价值代理，仍不是实际题目账单。日33、34达到120轮上限，其余3日按目标相对变化收敛；未宣称全局最优，也不能据此断言任何小时参数化都无效。

5个实际历史问题的24维中心差分最大误差不超过1.80e−8；两个涵盖零购电分段及近SOC下界的合成问题误差不超过5.87e−10。非光滑折点采用内点探针，不以折点中心差分作为全局可微声明。10个原/候选单日的物理与账单核验全部通过，原基线的充电、放电、紧急、弃余、SOC、费用数组均独立重构一致。

`conditional_comparison.csv`保留每一天历史目标、真实费用、末SOC及补偿；`planning_day*.npz`保留固定输入、原购电、小时变量和候选购电；`*_execution_day*.npz`保留逐槽实际执行。`audit.json`、`verification.json`与`synthetic_gradient_checks.json`分别保存优化/梯度、物理/账单和合成梯度核验。复现入口为`experiments/exp008/hourly_purchase_diagnostic.py`，未修改任何现有核心模块或基线档案。
