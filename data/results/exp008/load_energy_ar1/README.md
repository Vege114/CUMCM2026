# 固定在线AR(1)记忆候选：预测门槛未通过

这是唯一预先记录的在线拟合方案。`protocol.json`在生成、评分候选之前保存；未做增益/窗口/收缩强度网格，未修改固定0.5记忆版本或其结果。

对每个发布午夜，读取此前最多28个完整已发布Joint+Ridge28日的负载日均残差`r=actual−underlying forecast`，在该窗口内部取相邻日对`(x=r[t−1], y=r[t])`，最多27对。令`s²=max(mean(x²),1 kW²)`，最小化`Σ(y−φx)²/s² + 7(φ−0.5)²`，得到：

`φ = clip((Σxy + 7s²×0.5)/(Σx²+7s²), 0, 1)`。

无残差对时用0.5；无昨日正式预测时不校正。今日负载增加`φ×昨日underlying日均残差`并截非负；PV逐值不变。残差基准始终是未叠加任何记忆层的Joint+Ridge28，不递归使用已经校正过的预测残差。没有截距或全年度拟合，标准化仅使用当时历史。

## 因果与数值检查

6个日期切点（31/32/33/62/243/364）变异当日及未来实际值、未来基底预测后，截至当前发布的全部预测与tree28风险支持逐值不变；5个时点的规划适配器及其同管线历史误差路径重构差异0。PV差异0，所有拟合标签均为已完整观察日，系数全在[0,1]。3个独立数值测试验证闭式解与稠密穷举的一致性、边界/零信息情况、历史尺度不变性、28日窗口及前缀因果。

`prediction_audit.json`保存每天的历史origin、残差、成对origin、尺度、闭式系数与校正；`daily_coefficients.csv`便于检查系数序列。完整预测位于`predictions.npz`，分月/分组评分在`forecast_comparison.csv`，门槛在`prediction_gate.json`，来源及档案散列在`manifest.json`。

实现与独立适配器位于`experiments/exp008/load_energy_ar1.py`（`AR1MemoryStore`、`AR1MemoryForecasts`）；该失败候选没有替代现有固定0.5版本。复现：先运行`python -m experiments.exp008.load_energy_ar1`记录协议，再运行`python -m experiments.exp008.load_energy_ar1_audit`；使用项目`.venv/bin/python`并限制BLAS为单线程。
