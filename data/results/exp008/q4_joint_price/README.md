# 同日配对价格情景：固定 30 日未通过，停止扩展

使用原 Q4-2 physical 的 ridge28 预测、3 条初始化路径、每小时共同模式、50 元辅助换向代价、0.002 吞吐代价、5 秒/0.002 gap 和全 28 条路径的 greedy120 修正。唯一变更是价格：`P[j,t]=max(.01,当日已发布价格预测[t]+同一历史日价格残差[j,t])`。净需求和价格始终使用相同历史行及相同初始化选择索引。

共同 q 按 E[P] 计费，各场景紧急按 5P 计。初始化终端库存价值继续使用当前预测价最小值/ETA，greedy 终端代理保持 0.45。实际电价仅在购电和物理执行之后结算。本次使用新模块，没有改写正在运行的 `run_q4_physical.py`、原 physical 模型或原 closed_loop 模块。

真实费用增加 **942.01 元（0.071%）**，反转增加 12，未通过费用与反转同时改善的门槛，因此**不扩全年，不追加调参**。候选期末 SOC 多 2,486.78 kWh，单独披露，不抵扣成已实现节约。小额账单差、不同期末库存和有限精度整数初始化限制了长期优劣推断；本次只说明固定配置没有通过实际门槛，不否认已测得的价格/净需求相关性。

验证：

- 所有行价格相同时，新旧目标函数值和梯度逐位完全一致；小型 physical 初始化全部调度和场景数组也逐位一致。
- 不同场景价时，目标值与独立物理重算一致，解析梯度通过中央差分。
- 当日及以后所有实际负载/PV/价格污染，不影响净路径、价格矩阵、选中索引和预测价格。
- 每条初始化场景均满足功率/SOC/平衡/同槽充放互斥，禁止紧急充电；最大 MIP gap 为 0.00199947。实际 30 日及原基线的物理、源数据与账单复核通过。
- 仍是乐观情景补救与局部非凸 greedy 优化，没有完整非前视补救或全局最优证书。

接口：`joint_price_physical.plan(..., scenario_prices=P)`；`joint_price_closed_loop.objective/optimize(..., scenario_prices=P, ...)`，P 形状为 `(情景数,时段数)`。固定试验入口：

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python \
```
