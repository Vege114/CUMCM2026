# 固定购电计划下的执行诊断

本诊断沿用 Joint+Ridge28+三场景物理规划的全年购电量，比较储能执行。替代执行器的SOC虽真实连续，但购电计划保留原策略的虚拟SOC历史，未按替代SOC重新规划。因此结果只用于判断后续研究方向，不属于题目间模型已对齐的候选，不进入达标索引。

唯一新执行规则：每小时开始遵循原计划方向，当相反方向可执行功率达到1500kW时可切换一次，并保持到该小时末；只观察当前净负荷及当前SOC。

| 固定计划执行方式 | 全年真实费用/元 | 非空换向 | 末SOC/kWh |
|---|---:|---:|---:|
| 原小时方向 | 13,585,548.68 | 1665 | 1200.00 |
| 大动作方向覆盖 | 13,568,433.09 | 1665 | 1200.00 |
| 无方向限制greedy | 13,502,656.17 | 5157 | 1318.94 |

覆盖规则共触发163个小时，费用低17,115.59元（约0.126%）。该量级不足以解释距离8%费用目标的缺口，未据此重跑全年联合规划。原执行器重放所有共同数组最大误差为0，三条轨迹的独立物理与费用核验通过；任何原始检验中的目标字段不构成此执行诊断的最终候选资格。
