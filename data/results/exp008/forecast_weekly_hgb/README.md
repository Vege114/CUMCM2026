# 绝对量HGB每周重训：完整管线未通过门槛

本候选只把原HGB的月度重训改为从2月1日起每7天重训，共48个模型组、96个负荷/PV模型。原31个特征、HGB超参数、90日训练权重、发布前7日验证及原后处理不变。每组从头训练，当前及历史特征都只使用对应发布之前的实况。

原始净负荷RMSE从433.7401降低到406.1852kW。但按照预登记要求，比较完整Ridge28及非递归0.5负荷记忆管线时，四项都变差：

|334日完整管线指标|原月度HGB|每周HGB|
|---|---:|---:|
|净负荷RMSE，kW|362.899185|365.601381|
|高价槽净负荷RMSE，kW|348.184028|349.236522|
|全天净能量RMSE，kWh|3610.632811|3788.252756|
|累计前缀能量RMSE，kWh|2285.936945|2381.258071|

因此没有继续LP或年度储能规划。不能只引用原始预测改善来认定完整管线改进，也不据本试验断言所有重训频率都无效。

48组模型重载后逐值一致；最初7天原始输出与原月度HGB完全一致。7个日期未来实况及不等量未来预测变异不改变当前结果；日序31和241完整重训及首日预测变异检查通过。全部特征、训练/验证日期、标签与模型哈希见协议、逐组审计和`verification.json`。

另行命名的`weekly_hgb_aligned_calibration`用于诊断模型切换和校准参考是否有关，没有改写本次失败门槛。两个实验均属于已查看的2025年开发过程，不是独立测试或最终报告。
