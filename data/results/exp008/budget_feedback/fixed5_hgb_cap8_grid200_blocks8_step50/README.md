# 按剩余换向预算实时控制：固定五日开发诊断

本试验把固定充放时间表替换为能随当前观测变化的库存价值策略，同时保持每天最多 8 次实际非空方向反转。方向状态是上一非空真实方向；空闲时不清空方向；当天第一笔动作与前一天最后非空方向相反时，也消耗当天预算。

DP 状态为“时间、上一误差档、上一非空方向、剩余换向次数、SOC”。使用原绝对 HGB→Ridge28→固定 0.5 记忆预测和相同 28 条已完成历史误差，3 个误差档、每档 3 个保均值尾部分位代表点、200 kWh SOC 网格。当前误差观察后才决定动作；未来继续价值只知道当前误差档，不知道历史路径编号或未来观测。所有动作均遵守容量、效率和功率限制，禁止同时充放、紧急电充电及向已有余电放电。

五日的原始购电量、日初 SOC 和前一真实非空方向均从已完成 `hold1_cap8` 年度方案取出。每一天独立从该原日初状态开始，改变的日末 SOC 没有传播。因此下表只支持条件五日比较，不能外推年度节约。

同 Q 策略节省 7,001.2425 元，约 2.3131%。主要改善来自日序 151，且该日日末 SOC 没有减少。日序 243 多保留 1,008.5431 kWh 库存。次数、活动时间与吞吐变化并不一致，不能将结果描述为所有电池行为都减少或寿命延长。

Q 修正严格按预注册规则完成：8 个固定等长 18 时段块，一轮逐坐标 ±50 kWh，每天最多 17 个 Q。每次 Q 改变都重新计算 DP，并用新策略在全部 28 条已完成历史路径上的实际计费加 0.002 元/kWh 吞吐项、减终端库存项来选步。DP 的初始期望值另行记录，没有直接拿它选择 Q。

历史执行目标从 207,746.2635 元下降到 207,504.4486 元，改善 241.8148 元；对应 DP 初始近似期望从 205,442.3583 下降到 204,590.0115 元。然而 Q 修正使实际费用较同 Q 预算 DP 增加 1,939.5418 元。实际改善没有随历史优化转化。没有追加参数网格或再次选择坐标步长；后续年度候选不采用该块修正。

`independent_audit.json` 复算全部 85 个 Q 的 DP、全 28 条历史回放和顺序坐标选择，初始及选中策略的 10 组真实轨迹逐元素复现，并通过独立 `verify_arrays`。2,700 个独立标量 Bellman 计算最大误差为 2.91e−11；30 个非对称未来净负荷扰动不改变过去的 SOC、方向、剩余预算或动作。模型、来源日初状态和全部原始文件哈希也已核对。

这些验证证明实现遵循指定近似模型及物理约束，不证明误差过程是准确的 Markov 模型，也不证明连续状态全局最优。全部结果属于反复使用同一开发年度的开发实验。

后续只测试一个预先固定的连续 334 日候选：每天从自身真实 SOC 和上一真实非空方向重新生成物理 MIP 与既有全 28 路径贪心 Q 初值，再由预算 DP 执行。该 Q 初始算法仍使用固定掩码假设，是更灵活实际反馈控制的近似购电算法，不能声称已经精确联合优化 Q 与反馈策略。
