# 换向预算DP的SOC网格分辨率检查

在已经锁定的五日初始购电量、历史误差模型、真实日初SOC和上一非空方向下，仅将SOC网格从200kWh细化到100kWh。原始购电量不优化，剩余换向预算、尾部3点、磨损项和终端项不变。全部五个策略表先形成并锁定哈希，随后才读取当前日实况。

五日合计实际费用只减少27.0804元；相同28条历史路径下的策略目标合计减少30.1060元。这一有限差异没有提供把正在运行的全年200kWh网格方案中途改参的理由。

此结果不是连续年度收益。每个测试日沿用原年度方案各自日初状态，日末差额没有传到其他日期。`matched_metrics.csv`分别保存费用、反转、连续动作段起点、活动槽、吞吐和日末SOC；`deltas.csv`保留每一天“100减200”的差额，不能只引用费用而忽略库存差异。

连续动作段起点的最初诊断函数直接取sign，没有显式应用数值阈值。补充按既有核验器的1e−6kWh阈值重算后，五日两组的数量全部相同，没有发现浮点残差导致的虚增。检查记录在`episode_count_erratum.json`，阈值一致的表为`matched_metrics_thresholded.csv`与`deltas_thresholded.csv`。原始CSV及全部物理动作数组保持不变。

200kWh控制组与已签名实际轨迹逐值一致；新轨迹及全部历史回放通过SOC方程、容量/功率限制、供需平衡、5倍紧急费用、无同时充放和禁止紧急充电检查。15个未来净负荷变异均保持已执行前缀不变。所有原输入与策略文件哈希保持不变。

更细的网格并不自动保证实况费用更低：DP仍使用有限历史构造的误差状态模型及插值。此处只检查数值敏感性，不进行年度模型选择或宣称连续状态最优。
