## 复现

```sh
.venv/bin/python -m unittest discover -s tests -p test_q2_stochastic_lp.py -v
.venv/bin/python -m experiments.problem2.stochastic_lp.run --days 2 --out .work/exp005-reproduce
.venv/bin/python reports/build_report_exp005.py
```

输出目录必须不存在。`run`遇到D4失败保存 `certification_failure.json` 与
`status.json`，不会将失败结果标为完成。`model.py`只接受树、固定电价和状态，
不读取真实未来；`replay_day`只通过逐段回调接收实际供需。
本轮只有首日边界证据，信息树多分支和跨月全年表现尚未得到真实回放验证。
