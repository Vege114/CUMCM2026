# 实验记录

当前可运行版本位于 [baseline_v1/](baseline_v1/README.md)，其代码、参数、已核验的脱敏运行日志、图表和报告集中管理。每局输出自动保存至 `baseline_v1/runs/<run_id>/`，不会覆盖既有证据。

[运行报告](baseline_v1/REPORT.md) 包含 Q3/Q4 两场官方演练和六场离线结果；[比较索引](baseline_v1/benchmark_index.json) 可供后续版本读取。没有使用正式测试机会。

其他尚未核验或私有的运行输出仍可放在被忽略的 `experiments/runs/`。正式导出日志归档至 `submission/logs/problem3/` 或 `problem4/`，保持原名及内容。
