## 时间与展示口径

- 附件 2–4 覆盖 2025-01-01 至 2025-12-31；问题 2–4 的结果文件要求填写 2025-02-01 至 2025-12-31。1 月数据如何用于初始化或拟合，由后续模型明确说明。
- 指定展示日期：2025-03-20、2025-06-21、2025-09-23、2025-12-21。
- 表 1 的六个指定购电时段：10:00–10:10、12:00–12:10、14:00–14:10、16:00–16:10、18:00–18:10、20:00–20:10；另列全天购电量与购电费。
- 表 2 按六个 4 小时时段汇总充电量、放电量，另列 0:00 和 24:00 储电量。
- 表 3 列指定日期的紧急购电时间段与购电量；工作簿填写方式参照题目表 4。
- 题目以 10 分钟为计划购电结果间隔；每日对应 144 个区间。`0:00+1` 表示次日 0:00，即当日 24:00。
- 问题 3 的预报发布时刻为每天 0:00、6:00、12:00、18:00，每次预报覆盖未来 24 小时的整点光伏功率。

## 约束和计费要求

| 项目 | 题目给定值或要求 |
| --- | --- |
| 储能设备最大容量 | 12000 kWh |
| 最大充放电功率 | 5000 kW |
| 2025-01-01 0:00 初始储电量 | 6000 kWh |
| 后续储电量范围 | 1200–10800 kWh |
| 充放电效率 | 90%；后续模型需写明效率进入状态方程的方式 |
| 问题 1 日末约束 | 0:00 与 24:00 储电量相同，供电不可低于负载 |
| 问题 2 紧急购电 | 供电不足时从外网购电，交易时刻电价的 5 倍 |
| 问题 2 其他购电费用 | 按计划购电量计算 |
| 问题 3 计划量高于调整量的部分 | 违约电价为交易时刻电价的 50% |
| 问题 3 调整量高于计划量的部分 | 超出部分电价为交易时刻电价的 1.5 倍 |
| 问题 3 总费用 | 包括计划购电、紧急购电及调整购电量相关费用 |
